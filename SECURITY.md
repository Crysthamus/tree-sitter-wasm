# Security Policy

This document outlines the security procedures and general policies for the project.
For non-security issues, please open an issue in the repo.

## Reporting a Vulnerability
**Do not open a public GitHub Issue for security bugs.**
Instead, please use one of the following secure methods to report vulnerabilities:

### GitHub Private Vulnerability Reporting (Preferred)
You can submit your report directly through GitHub:
1. Navigate to the main page of the repository.
2. Click on the **Security** tab.
3. On the left sidebar, click **Advisories**.
4. Click **Report a vulnerability** to open the advisory form.

### Email
You may report the vulnerability via email to [crysthamus@gmail.com](mailto:crysthamus@gmail.com).

## Responsible Disclosure
Please do not publicly disclose details until the issue has been fixed.

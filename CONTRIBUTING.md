# Contributing to tree-sitter-wasm
First off, thank you for considering contributing to `tree-sitter-wasm`! It's people like you that make this tool reliable and secure for everyone.
This document describes the process for contributing to the project. It is intended for anyone who is considering opening an **issue** or **pull request**.

## AI Usage
AI usage is allowed however, you must make sure to self-review code before opening a PR or filing an issue.

## Adding/Updating Parsers
Please **don't** open pull requests that add/update parsers, instead open an issue.

## Pull Requests
When you are ready to submit your changes, please open a Pull Request (PR) against the main repository.
Ensure your PR description clearly states what is being added or deleted and the purpose of the pull request.
